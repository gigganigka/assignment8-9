# iPhone и Web: запуск с Windows

Это исходный проект с командами сборки. Готовых Web-файлов, Xcode-проекта и подписанной IPA в архиве нет: здесь Unity не установлен. Команды должны быть выполнены на компьютере с Unity 6 и соответствующими модулями. iOS и Web компиляция пока не проверены.

## 1. Открыть

Распакуй архив в отдельную папку. Unity Hub -> Add project from disk -> Coinbound. Дождись пакетов. Tools -> Mobile Game -> 1. Prepare Project and Bake UI. Открой mainmenu и проверь Play в редакторе.

## 2. Web на Windows, затем Safari на iPhone

1. Unity Hub -> Installs -> меню своей Unity -> Add modules -> Web Build Support (в некоторых версиях называется WebGL Build Support).
2. Unity: File -> Build Profiles -> Web -> Switch Platform. Дождись завершения импорта.
3. Tools -> Mobile Game -> 5. Build Web (Safari).
4. При успехе появится Builds/Web/index.html и папка Build с настоящими data/wasm/framework/loader файлами. Двойной щелчок по index.html не подходит: нужен HTTP-сервер.
5. Установи Python 3, если его ещё нет. Открой терминал в корне Coinbound и выполни:

       py Tools/serve_web.py

6. Разреши Python в брандмауэре Windows только для частной сети. Телефон и ПК должны быть в одной доверенной Wi-Fi сети, без изоляции клиентов.
7. Сервер напечатает адрес вида http://192.168.1.5:8000. Открой этот адрес на iPhone в Safari, поверни телефон горизонтально и нажми PLAY.
8. Для остановки сервера нажми Ctrl+C. Для локального тестирования пробрасывать порт роутера не нужно.

Если адрес недоступен: проверь IP компьютера через ipconfig, одинаковую сеть, VPN, гостевую Wi-Fi сеть и правила брандмауэра. Сначала проверь http://localhost:8000 на самом ПК.

Web-шаблон ограничивает плотность пикселей до 2, учитывает CSS safe-area, показывает прогресс и просит горизонтальную ориентацию. Движение/JUMP/FIRE принимают отдельные пальцы. Кнопка Quit выводит подсказку закрыть вкладку: браузер нельзя закрывать как приложение.

После успешного теста можно разместить СОДЕРЖИМОЕ Builds/Web на статическом HTTPS-хостинге с MIME application/wasm. Сохраняй все имена файлов и папки. Серверные gzip/Brotli-настройки не нужны: эта команда создаёт несжатую сборку. Размер загрузки будет больше. Сборка не была опубликована и публичной ссылки пока нет.

## 3. Экспорт iOS на Windows

1. Unity Hub -> Add modules -> iOS Build Support для той же версии Unity.
2. File -> Build Profiles -> iOS -> Switch Platform; дождись импорта.
3. Tools -> Mobile Game -> 4. Export iOS Xcode Project.
4. При успешном экспорте Builds/iOS содержит Xcode-проект. Это НЕ IPA и не устанавливаемый файл.

Настройки экспорта: IL2CPP, Metal, iPhone/iPad, iOS 15+, landscape left/right. Bundle Identifier по умолчанию com.student.coinbound: для подписи выбери свой уникальный идентификатор. Team ID и сертификаты намеренно не придуманы и не включены.

Дальше необходим Mac/Xcode (локальный или удалённый) и подходящая подпись. На Mac можно выбрать Apple ID Personal Team для ограниченного личного тестирования без платной подписки; ограничения проверь по актуальной документации Apple. TestFlight и App Store требуют соответствующего участия в Apple Developer Program. Облачный сервис не отменяет требования к подписи. В твоей текущей ситуации без Mac и аккаунта разработчика Web доступнее; IPA не обещана.

## 4. Что проверить

- Меню -> Play -> уровень; джойстик двигает героя и отпускается без залипания.
- Одновременные движение + прыжок + стрельба.
- Pause/Resume/Restart/Main Menu; смерть и повторный запуск.
- Переключение вкладок/сворачивание, возврат и Resume.
- Safari в горизонтальной ориентации: вырез, нижняя полоса, кнопки не закрыты.
- Два уровня, босс и победа; звук после взаимодействия пользователя.
- Device Simulator: 16:9, notch phone, 4:3 tablet.

Web-тест не подтверждает работу нативной iOS-сборки. Remote-тест тоже не заменяет IPA.
