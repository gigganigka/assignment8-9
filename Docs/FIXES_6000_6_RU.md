# Обновление для Unity 6000.6.2f1

## Что изменено

- Версия проекта: 6000.6.2f1. Пакеты: Input System 1.20.1, URP 17.6.0.
- UIActionButton хранит действие кнопки как сериализованное поле и подключает обработчик при запуске. Сохранение/открытие baked-сцены больше не должно терять действие кнопки.
- MobileGameUI.Start повторно создаёт интерфейс, если стартовая инициализация не произошла.
- GameScenes объединяет переходы. В редакторе может открыть включённую в проект сцену напрямую, даже до подготовки списка сборки. В готовой игре отсутствующая сцена даёт сообщение и ошибку Console вместо молчания.
- Главный экран: короткий заголовок и описание, портрет NOVA, Play/Settings/Quit. Настройки вынесены отдельно; значения изменяются большими кнопками, без громоздких слайдеров.
- Компактные карточки HUD, скруглённые панели и кнопки, исправленная тонкая полоска здоровья босса. Минимальный размер текста 36, перенос и автомасштабирование.
- Скин NOVA: использованы существующие цветные sprites tile_0009/0010 из присланного набора. Skin применяется после Animator и использует unlit-материал, чтобы не становиться тёмным из-за освещения. Загрузка Multiple sprites выполняется через LoadAll.
- Новая команда сборки Windows. Настройки Web и iOS сохранены.

## Как открыть чисто

1. Распакуй НОВУЮ версию в отдельную папку. Не смешивай с предыдущей папкой Library/Packages.
2. Добавь папку Coinbound через Unity Hub, выбери 6000.6.2f1.
3. Дождись восстановления пакетов. Не запускай Play, пока есть ошибки компиляции.
4. Вне Play Mode: Tools -> Mobile Game -> 1. Prepare Project and Bake UI.
5. Открой Assets/mainmenu.unity. Переключись на вкладку GAME. Выключи Gizmos, чтобы не видеть оси и значки редактора.
6. Нажми верхнюю кнопку Play. Кнопка Pause рядом должна быть ВЫКЛЮЧЕНА. Нажми PLAY внутри игры.

Нажатия в Scene view и в Edit Mode не запускают игру. На твоём снимке видны оси редактора: это не часть интерфейса.

## Windows

File -> Build Profiles -> Windows -> Switch Platform (x86-64). Затем Tools -> Mobile Game -> 6. Build Windows EXE.
При успешной сборке: Builds/Windows/Coinbound.exe. Передавай всю папку Windows, включая Coinbound_Data, UnityPlayer.dll и прочие созданные Unity файлы.

Управление: A/D или стрелки, Space для прыжка, X для стрельбы, Escape для паузы. Можно нажимать экранные кнопки мышью.

## iPhone

Доступный путь без Mac: Web в Safari. File -> Build Profiles -> Web -> Switch Platform, затем Tools -> Mobile Game -> 5. Build Web (Safari). После успеха из корня проекта: py Tools/serve_web.py. Открой напечатанный адрес на iPhone в той же Wi-Fi сети. Подробнее IOS_WEB_RU.md.

Команда 4 экспортирует только iOS-проект для Xcode, не подписанную IPA.
