# Assignment 10: три врага

## Запуск

1. Открой эту версию проекта через Unity 6000.6.2f1. Дождись компиляции.
2. Tools -> Mobile Game -> 1. Prepare Project and Bake UI.
3. Открой mainmenu и нажми Play: теперь сначала открывается enemy_lab.
4. Альтернатива: Tools -> Assignment 10 -> Open Enemy Lab, затем Play в окне Game.
5. Три врага появляются на общей площадке при запуске. Пока игра остановлена, сцена содержит копию исходного level1; EnemyLabBootstrap заменяет геометрию в Awake. Это намеренное устройство уровня. Для настройки арены меняй сериализованные поля EnemyLabBootstrap, для настройки поведения - assets ниже.
6. Победи всех трёх и дойди до зелёного флага справа. Затем начинается исходный level1 и обычная кампания.

Телефон: имеющиеся TouchStick/JUMP/FIRE, Unity Remote или Web/Safari. Для iPhone в задании разрешена запись с телефона вместо APK. Добавление AI не является подтверждением работы нативной IPA.

В enemy_lab враги принудительно включены для проверки задания. Дальнейшие уровни сохраняют прежние поведения: старый PatrolEnemy и босс не заменялись.

## Настройка после теста

В Assets/Resources/EnemyLab открой PatrollerSettings, ShooterSettings, ChargerSettings. Изменения в этих ScriptableObject сохраняются вне Play Mode и попадут в Git.

Начальные значения (ещё НЕ результат плейтеста):

| Тип | Подготовка | Перезарядка | Урон | HP |
|---|---:|---:|---:|---:|
| Patroller | 0.6 с | 1.3 с | 1 | 2 |
| Shooter | 0.7 с | 1.8 с | 1 | 2 |
| Charger | 0.8 с | 1.6 с | 1 | 2 |

Скорость ходьбы 1.6, преследования 2.3, рывка 6; рывок длится 0.6 с. Видимость: 6 единиц, угол 150 градусов. Изменяй реальные значения после наблюдения за двумя тестировщиками. Не переписывай исходные значения в протоколе задним числом.

## Что происходит

- Patroller: Patrol -> Chase -> WindUp -> Recover. Теряет цель за стеной/после потери видимости. Удар в конце предупреждения можно избежать, отойдя или зайдя за спину.
- Shooter: Idle -> Aim -> Shoot -> Cooldown. Прицел фиксируется в начале подготовки: игрок может уйти с линии выстрела.
- Charger: Patrol -> WindUp -> Charge -> Recover. Направление рывка фиксируется, стена/край/выход за экран останавливают рывок.
- Красная окраска и ! над врагом предупреждают об атаке. Восстановление даёт окно для ответного выстрела.
- Только Ground (слой 6) блокирует обзор. Укрытия уровня относятся к нему; триггеры игнорируются.
- Пули игрока работают через существующий IDamageable. Урон герою идёт через Health.TakeDamage с исходной неуязвимостью.
- Контакт с новым врагом сам по себе не наносит скрытый урон: требуется явная атака после подготовки.
- Прыжком можно уйти от выстрела/рывка; укрытия блокируют обзор и снаряды.

## Проверка в Unity

Tools -> Assignment 10 -> Validate encounter проверяет наличие настроек. В Play Mode enemy_lab также проверяет присутствие трёх врагов. После победы проверка присутствия врагов закономерно не пройдёт.

Проверь руками: вход/выход из поля зрения, стену между игроком и врагом, уход с экрана во время подготовки/рывка, паузу во всех состояниях, смерть героя, рестарт, убийство врагов пулей и переход по флагу. Затем повтори на телефоне.

Unity, Xcode и физического телефона здесь нет. Эти изменения не были запущены или скомпилированы в Unity; ошибки компиляции/импорта и баланс ещё могут потребовать исправлений. Цель 2-4 попытки не подтверждена. При ошибке пришли первую красную строку Console полностью.
