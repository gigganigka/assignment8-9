# Звук

Автоматически подключены имеющиеся в присланном проекте WAV-файлы: jump (прыжок), coin (монета), hurt (урон), music (зацикленная инструментальная фоновая музыка). Новая песня с вокалом не создавалась.

GameAudio назначает недостающие клипы при загрузке любой игровой сцены. У событий есть Resources-fallback. Music сохраняется между сценами и удаляет дубликаты: музыка не начинается заново при каждом переходе. Фон тише эффектов, пауза останавливает музыку; звук последнего удара может закончиться поверх экрана смерти.

Установка поверх уже работающего проекта: закрой Unity, сделай резервную копию и перенеси из архива только Assets/Scripts/GameAudio.cs (+ meta), Music.cs, Sfx.cs, PlayerController.cs, Health.cs, Collectible.cs и папку Assets/Resources/GameAudio вместе с meta. Library/PackageCache не заменяй: рабочее исправление Unity Remote не нужно трогать. Альтернатива: открыть весь архив в отдельной папке.

Запусти mainmenu -> Play, прыгни, возьми монету, получи урон. Проверь Pause/Resume и переход уровня: фоновый трек должен продолжаться без наложения. Здесь проверено наличие PCM-данных и корректность WAV, но прослушивание в Unity и на iPhone не выполнялось.

Если тишина: проверь громкость Windows/телефона, Mute Audio в окне Game и наличие AudioListener у камеры. Safari требует взаимодействия с игрой для запуска аудио. Unity Remote не следует использовать как подтверждение воспроизведения аудио на телефоне: сначала проверь колонки/наушники ПК, для реального телефона проверь Web-сборку в Safari.
